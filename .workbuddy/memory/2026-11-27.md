# 2026-11-27 工作日志

## 修复：在线模式送将/照面非法落点无特效提示
- 现象：在线对局点击送将落点（如黑炮横移把自己变成红炮炮架）静默无反馈，本地热座模式却有红色脉冲特效。
- 根因：送将/照面警示逻辑只写在 `pages/game/game.js` 的本地分支 `onBoardTap`，在线分支 `_onBoardTapOnline` 缺失。
- 修复：抽取公共方法 `_warnIllegalMove(index, board, selected, turn)`，返回 true 表示已处理非法落点；本地分支传 `turn`、在线分支传 `this.data.seat`，两处共用，保留 facingSeq/selfCheckSeq 序号递增重播。
- 验证：新增 2 项在线测试（送将、照面），全部测试通过（规则 15 / 房间 10 / 云函数 9 / UI 47），语法检查通过。

## 功能：对手离开房间增加胜负判断与结算
- 根因：`leaveRoom` 虽然写了 winner/loser，但没有更新 lastMove；而前端结算特效、状态文字、提示音全由 lastMove 驱动，导致对手离开后留下的玩家看不到胜负结算。
- 修复：`utils/room.js` 与 `cloudfunctions/room/room.js` 两副本同步改造——对局中离开写入结算型 lastMove（含 winner/loser/loserKing/statusText/reason:'leave'）；等待阶段离开只解散房间不判胜负；已结束对局离开保留原胜负不覆盖。
- 云函数 leave 分支用 `_.set(lastMove)` 整体替换，避免初始 null 时 SDK 展开子字段报 "Cannot create field"（与 move 分支同坑）。
- 客户端 `_applyRoom` 对 `last.reason === 'leave'` 弹一次结算提示，不再播放落子音效。
- 验证：新增 5 项测试（房间 4 + 云函数 1 + UI 2 中的部分），全部通过（规则 15 / 房间 14 / 云函数 10 / UI 49），语法检查通过。

## 修复：在线模式吃子特效时有时无
- 根因：棋盘组件用 `highlight.captureSeq` 作为特效节点 `wx:key` 来重建并重播 CSS 动画；云函数写入的 `lastMove` 不含 captureSeq，页面 `_applyRoom` 虽递增了 `this.data.captureSeq` 却没传给组件，导致组件拿到恒为 0，连续吃子时 key 不变、节点复用、动画不重播（隔一次普通走子又偶然出现）。
- 修复：`_applyRoom` 里先算 `nextCaptureSeq`（仅新吃子递增），用 `Object.assign({}, last, { captureSeq: nextCaptureSeq })` 构造 highlight，同时写入 data 并传给 `_applyHighlight`；重复推送不递增、不重播。本地模式本来就带 captureSeq 不受影响。
- 验证：新增 3 项在线 UI 测试（连续吃子递增、与普通走子交替、重复推送不重播），全部通过（规则 15 / 房间 14 / 云函数 10 / UI 52），语法检查通过。
